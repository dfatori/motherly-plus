# Archived analysis scripts

These scripts are **not part of the pre-registered statistical analysis plan**
for the Motherly+ RCT3. They were moved here because moderation, mediation, and
process (therapeutic alliance / app engagement) analyses will **not** be
pre-registered.

They are kept for reference only and are **not** run by `scripts/run-all.r`.
If any of these analyses are later conducted, they must be reported as
**post-hoc / exploratory**, not confirmatory.

| Script | Original purpose |
|---|---|
| `20_moderation-analysis.r` | Moderation of the treatment effect on QIDS-C16 at T3 |
| `21_mediation-analysis.r` | Parallel mediation (BADS-SF and RPI change, T1 to T2) |
| `22_process-analysis.r` | Therapeutic alliance (WAI-SR) and app engagement |
